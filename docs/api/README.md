# Hợp đồng API

Tài liệu thiết kế nguồn: ../06-hop-dong-api.md và ../08-khuyen-mai-chat-tra-hang-danh-gia.md. Khi triển khai từng lát cắt, bổ sung OpenAPI cho dịch vụ tương ứng tại đây hoặc sinh từ mã. Chốt request/response, lỗi, quyền, idempotency và phiên bản trước khi gọi chéo. API demo hiện dùng /api; mục tiêu /api/v1 cần chuyển đổi đồng bộ frontend và Gateway.
